hello-world ローカル練習

TenkaCloudの実採点処理に接続した開発用画面です。実AWSは使いません。10分の一時練習で、終了すると状態を削除します。

  1. ホストが作成した自分のチームのJSONファイルからTeam keyを入力します。
  2. 同じファイルのconsoleUrlを開き、consoleTokenでサインインします。
  3. Services → Systems Manager → 東京リージョン ap-northeast-1 → Parameter Store → パラメータ名 → OverviewのValueを読みます。
  4. 読み取った値をそのまま提出します。正答100点、誤答5点減点、加点は1回です。

AWS資格情報・CloudShell・AWS Console URLはこのローカル接続では使用しません。
