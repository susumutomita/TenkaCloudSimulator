AWS · リクエストの入口

API Gateway

ローカル REST API のルートから、保存済みの Lambda 関数を呼び出す構成例です。

REGIONAL / AWS_PROXY の限定的な実装です。公開ウェブサイトのホスティングや、実 AWS への接続は行いません。

コンソールで対応範囲を確認

AWS · Python をローカル実行

Lambda

埋め込みの CPython / WASI で Python 関数を実行します。保存済みの実行ロールに基づき、限定された S3・SSM 操作を呼び出せます。

任意の HTTP 通信やホストのファイルアクセスはできません。S3 への書き込みが関数を自動起動する構成ではありません。

コンソールで対応範囲を確認

AWS · バケットとオブジェクト

S3

バケットやオブジェクトを操作し、コンソールと API から同じローカルデータを確認できます。

Lambda 内 SDK の対応範囲は GetObject・PutObject・DeleteObject です。図の線は関数からの明示的な呼び出し例です。

コンソールで対応範囲を確認

AWS · Standard パラメータ

Systems Manager

Standard パラメータを保存し、関数から GetParameter・GetParameters で参照する流れを試せます。

SecureString と実 KMS による暗号化は対応範囲外です。練習用の値だけを使用してください。

コンソールで対応範囲を確認

AWS · 実行ロールの権限

IAM

保存済みの実行ロールとローカルポリシーが、関数からのサービス操作を制限します。

実 AWS の STS・フェデレーションや、クラウド全体の IAM を再現するものではありません。

コンソールで対応範囲を確認

Google Cloud · ローカルのバケット

Cloud Storage

ホストが設定した固定プロジェクトの範囲で、バケットとオブジェクトの限定的な JSON API を扱います。

Google IAM・OAuth や任意のプロジェクト作成は再現しません。利用できる範囲はホストの設定によります。

コンソールで対応範囲を確認

Google Cloud · 内容と世代条件

Object

オブジェクトの内容やメタデータを読み書きし、世代条件を使った操作を試せます。

図はバケットとオブジェクトの所属関係です。AWS 側から自動転送される構成ではありません。

コンソールで対応範囲を確認

Azure · 固定アカウントの保存先

Container

ホストが設定したローカルのストレージアカウントで、コンテナーと Blob を操作します。

Azure RBAC・Entra・SAS やアカウント作成は再現しません。利用できる範囲はホストの設定によります。

コンソールで対応範囲を確認

Azure · 内容と ETag 条件

Blob Storage

BlockBlob のアップロードやダウンロード、ETag 条件を伴う操作をローカルで試せます。

図はコンテナーと Blob の所属関係です。ステージングしたブロックや実クラウドの認証は対応範囲外です。

コンソールで対応範囲を確認
01

同じローカルデータを見る

コンソールと API は同じ SQLite 状態を利用します。ファイルへの保存は起動時の設定で選べます。

02

権限も、練習の一部

ローカル認証と実行コンテキストを区別します。別チームには別プロセス・DB・トークンを用意してください。

03

できないことも明確に

クラウド全体の互換実装ではありません。未対応の機能を、動作するものとして見せません。
