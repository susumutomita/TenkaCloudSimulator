Open interactive API reference ↗

Use the endpoint below with the AWS CLI or an S3 SDK. Use path-style addressing and simulator-only credentials. No AWS account is needed. 


        
        
Supported operations

        

          ListBuckets, CreateBucket, HeadBucket, GetBucketLocation,
          DeleteBucket, ListObjectsV2, PutObject, GetObject, HeadObject,
          DeleteObject.
        

        
Deliberate boundaries

        

          8 MiB per object · 64 MiB total · 1,000 buckets · 10,000 objects. The
          default SQLite database is in memory and resets on exit. Identity
          policy Allow/Deny rules are enforced for the selected principal.
          Conditions, resource policies, ACLs, boundaries, and SCPs are
          unsupported and rejected. No signature verification, multipart
          uploads, or versioning. Add --state to persist SQLite state. Use a
          trusted local environment.
        

        

          The console uses the same S3 HTTP API as your tools. Other cloud
          services are not implemented.
