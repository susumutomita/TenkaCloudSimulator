# S3のバージョンとbucket設定

既存10操作にGet/PutBucketVersioning、ListObjectVersions、Get/Put/DeletePublicAccessBlockを追加。SDK/UI/Scalarは同じHTTP/stateを使う。CloudFormation S3、ACL、bucket policy、account/organization public-access-block、access points、multipart、copy、conditional DELETE、Object Lock、lifecycle、replication、MFA Deleteは未対応。設定を無効にしてもpublic grantは作られない。

## 保存と削除

未設定bucketではPUTが現在値を置換し、DELETEは永久削除。Enable後のPUTにはopaque version IDが付く。DELETEは新しいdelete markerをcurrentにし、通常GET/HEADは404。特定markerのGET/HEADは405、x-amz-delete-markerとLast-Modifiedを返す。versionIdは1–128のprintable UTF-8 bytes（当Simulatorが生成するIDはhexまたはnull）。versionIdを指定したDELETEはその版だけを永久削除する。currentを消すと残った最新の版がcurrentになる。marker除去で旧objectが戻る。取り消した版自体は復元できない。

Suspendedは既存のnumbered versionsを保持し、PUT/DELETEでnull版を置換する。再Enableしてもnull版/markerを消さない。無効状態へ戻す操作はない。未設定時GetBucketVersioningはStatusを省略。設定の反映は即時であり、実AWSの伝播待ち時間は再現しない。

AWS所有のaws_s3_versionsが履歴を保存する。provider中立objectsはcurrentの共有viewで、両方を単一immediate transactionで変更する。既存SQLiteの無version objectは内容を保持したnull版として遅延importする。旧状態ファイルのschema versionは変更しない。new bucketはAWSの現在の既定に合わせpublic-access-blockの4値をtrueで初期化。旧bucketの未設定値を勝手に書き換えない。

Content-Typeは1024 UTF-8 bytes以下に制限し、body以外の履歴metadataによる無制限な増大も防ぐ。keyは既存の1024 UTF-8 bytes上限。

64 MiB/10000の保存quotaは全retained versions/markersと未import objectを数え、current viewの重複を除く。markerも1entry、null置換は置換対象だけを解放。上限拒否/SQL失敗で履歴とcurrentの一部を残さない。bucket削除はcurrentが空でもhistory/markerが残っていればBucketNotEmpty。自動削除やquota逃れのための履歴削除はしない。

## IAMとページ送り

version指定GET/HEADはs3:GetObjectVersion、DELETEはs3:DeleteObjectVersion、一覧はs3:ListBucketVersions。通常版は既存GetObject/DeleteObject/ListBucket。Get/PutBucketVersioning、Get/PutBucketPublicAccessBlockはbucket ARNへ評価。DeletePublicAccessBlockにもPutBucketPublicAccessBlockを使用。実署名/STSではなく既存local token境界と限定identity policyの範囲。

ListObjectVersionsはkey昇順・同key内の新しい版から返す。prefix/delimiter/max-keys(0–1000)/encoding-type=urlとkey-marker/version-id-markerに対応。cursorのIDはopaqueで、既存の同じkeyの版を指定する。削除されたcursorはInvalidArgumentとして再取得を要求する（実AWSの全cursor挙動とは一致を保証しない）。Owner/checksum/restore metadataは省略。unsupported/重複/混在queryやXML fieldsは明示エラー。
