# Narrow dispatch policy abstraction

Existing accepted ARPTrustedReply remains unchanged. This additional model covers only new MatchesReply and owner frame classifier composition. Canonical 60-byte reply is represented by fourteen distinct fields including padding. Each field is independently corrupted once; nil/zero responder are represented by present/ready flags. The equality oracle uses original immutable configuration, separately from captured implementation input and mutated caller record. These are finite field witnesses, not byte-parser proof. Native every-byte mutation/length tests remain independent obligations.

Owner frame dispatch uses explicit optional ARP/passive policies and invalid/to/from directions. ARP request validity is delegated to existing ARPTrustedReply/native parser; request/badrequest distinguish that already-validated result and are not a new proof of requests. Reply fields are validated here. Non-TCP classes cannot fall into TCP acceptance. EtherType branch abstraction follows those classes; malformed EtherType cannot gain acceptance in these witnesses but every byte encoding is not enumerated.

TCP tuples are normalized as the source does after direction selection; model covers exact probe versus independent passive whitelist and reserved source-port boundaries, not wire orientation transformation or ParseTCPFrame implementation. Probe local port40100 is deliberately valid in the independent oracle, despite being a +100 mutation of40000. Passive peer port is wildcard, while all fixed fields remain checked. Constructor rejects probe/passive overlap; model fixes disjoint tuples as that prerequisite, not proof of the constructor.

The source boundary is `ARPResponder.MatchesReply` and its shared trusted reply encoder in `internal/workload/guestnet/arp.go`, plus the copied descriptor and frame classifier in `internal/workload/guesttcp/owned_probe_session.go`. Source scope indicates these methods only; matching a path does not imply whole-file coverage. Lifecycle is separately modeled.
