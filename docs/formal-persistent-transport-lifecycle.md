# Persistent lifecycle scope and residual obligations

This is an atomic bookkeeping model, exhaustive over a small finite one-shot abstraction, not a refinement proof of complete Go files. Initial state assumes successful constructor ownership transfer and one admitted child. Invalid constructors, eight-slot production cardinalities and unbounded repeated traffic are not modeled.

- `Enqueue` / `Select` / `WriterExit`: persistentNIC.submit/write queue lock, fixed capacity, selected callback and final sealed drain. Queued producers cannot abandon acknowledgment on cancellation. A sender that already obtained a frame can still enqueue after graceful probe close while its pump is live. In `transport_persistent.go:352–364`, send reads with the pump context but submits using the session lifetime; `404–430` checks that lifetime/shared admission/queue seal, not p.closing. The writer checks p.closing and rejects the queued request at `455–468` before selecting its callback; graceful close does not retroactively revoke already selected output.
- `Enter` / `Return`: Transport.commitContext admission checks before callback and after return. Enter records a possible effect, not guaranteed bytes delivered. Expiry can race an entered callback and leave that effect; it cannot become successful after expiry. The model does not implement the trusted owner's atomic physical fence or prove malicious callback containment. Return has no callback-error/outcome input: only post-return admission/lifetime accounting is modeled, not owner error propagation or every successful-return condition.
- `CloseProbe`, pump joins, `JoinChild`: ProbeExchange.beginClose/supervise waits for both pumps, engine close, outstanding Dial and actual session teardown before deleting the child. Session and engine teardown are abstracted by the join signal, not separately verified here. Normal retirement leaves shared service lifetime intact.
- `CloseWhole`, independent `CloseStream`/`CloseService`, `Finish`: Transport.supervise initiates separate Close calls, joins child work and base workers, then receives both results. An error returns done but retains capacity; pending calls cannot release capacity. Model results 1/2 denote success/error, not physical verification.
- `Expire` abstracts entered probe expiry causing registry failure propagation to shared admission. Unentered probe expiry does not imply shared transport failure. Passive-service expiry is represented by whole closure, not a renewable lease.

Native test witnesses include TestPersistentQueuedProbeRetiresBeforeWriterAdmission, TestPersistentEnteredProbeExpiryFencesWriterAndRetainsDebt, TestPersistentFailedEndpointAndCloseRetainSharedDebt, TestPersistentOpenShutdownRaceJoinsEveryChild, TestPersistentWriterExitSealsEnqueue, TestPersistentGracefulCloseJoinsSelectedWriteWithoutRevokingSibling, TestPersistentUnenteredTransmitExpiryKeepsSharedWriter and TestFramedTransportCommitJoinsRacingCallback. Their prior execution is separate evidence; this work does not rerun or replace them.

## Explicitly not covered

engine.go and listener.go own gVisor endpoints, bounded IO and packet injection; http_observation.go owns protocol parsing, caller budgets and result publication. Those need independent models/source validation. passive_lifetime.go, transport_passive.go and transport_service.go constructor/deadline/route validation are not mapped by this model. Shared transport.go framing/ARP/accounting/owner misuse branches also remain unmodeled; any registration naming this file must retain those residual obligations rather than declare whole-file coverage.

The new gvisor.dev/gvisor pin, github.com/google/btree, golang.org/x/exp and golang.org/x/time in go.mod/go.sum require exact-source/checksum/provenance and vulnerability validation independently. Modeling orchestration does not establish dependency correctness or justify metadata-only exemption. Existing WAF module obligations remain unchanged. Packet/route model work is separate; neither model demonstrates production physical authority or a usable Battle.
