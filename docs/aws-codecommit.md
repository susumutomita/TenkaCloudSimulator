# AWS CodeCommit

Create a local repository with the official CodeCommit client. Its first `PutFile` creates the named branch, stores the file and sets the repository's default branch. Pass the current branch head as `parentCommitId` on later writes. A competing writer must read the latest head before retrying. `CreateBranch` starts another branch at a commit already held by the same repository.

`GetFile` returns the saved binary bytes, mode, size, path, commit and blob IDs. Omit `commitSpecifier` for the default branch, or specify a branch name, `refs/heads/<name>` or a full lowercase SHA-1 commit ID. `GetCommit` returns the root tree ID, parents, author, committer and message. The simulator writes the Git object header, sorted tree entries and commit text in Go. It retains previous revisions after a branch advances. The registered URLs in `GetRepository` are AWS metadata. The local simulator serves the JSON API on its own authenticated origin.

Each operation evaluates its CodeCommit IAM action on `arn:aws:codecommit:<region>:<account>:<repository>`. Team databases, regions and repositories have separate histories. Removing a repository removes its branch tips and objects. A repository created later under the same name starts empty. A configured customer KMS key makes content operations unavailable.

The local limits are 64 KiB per file, 256 bytes and eight components per path, 32 branches and 512 distinct Git objects per repository, and 32 MiB of object bodies per team. A single commit can add or update one regular or executable file. An omitted mode preserves an existing file's permissions and defaults a new file to regular. Commit messages are at most 4,096 bytes. When author information is omitted the simulator uses `Local contributor <local@simulator.invalid>` with its UTC clock. The optional author name and email become part of the Git commit itself. `ListBranches` returns ten names at a time. IAM conditions involving tags or ref names, Git clone/push transports, symbolic links, merges, pull requests, triggers and notifications are outside this subset.
