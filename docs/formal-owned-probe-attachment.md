# Attachment lifecycle correspondence

The source boundary is `internal/workload/guesttcp/owned_probe_attachment.go`. The owner-local lifecycle model remains a separate obligation.

Start after NewOwnedPersistentProbeSession has validated/captured its descriptor and transferred its resource to the owner. Attempt represents the ioMu-serialized attached flag check/set, shared with owner Revoke. Caller expiry blocks reservation and final publication, but does not become transport lifetime; NewPersistentTransportUntil receives s.ctx. Construct does not hold the frame gate or ioMu. BuildReturn is actual constructor result; transfer is recorded at the following RetainTransport action before any returned handle is visible. Failed construction leaves passive service with caller. Successful construction transfers service even when owner revoke raced, and bind/postcheck failure retains transport debt and cleanup handle. Bind uses only the captured descriptor. Publish serializes its current check with Revoke via ioMu; subsequent revoke may occur before successful Attach returns, so returned scope is not a promise of ongoing validity.

Failure path separately seals owner, initiates transport close if retained, then returns nonnil handle. There is no reset of attached flag. Lifetime cancellation may notify a successful transport separately, including before its handle field is assigned. OwnerDone represents actual raw Close/I/O/gate join, transport Done its independent component completion; neither waits on the other's abstract state. Parent component models/native composition tests establish internal ordering. Owner slot may release while transport still holds debt. Wait success needs both components (only owner for failed constructor). Caller Wait timeout/errors do not release slots; omitted wait-failure calls stutter. No fairness/liveness or deadlock-freedom is inferred.

Native obligations not encoded: descriptor deep-copy/validation, Stream/Transact same-resource issuance, strict passive tuple and ARP canonical bytes, pointer aliases and provider physical authority, exact constructor service ownership contract, independent capacity eight-slot counters and real synchronous mutex behavior. Descriptor marker immutability only represents no later replacement. AdmissionOnlyContext is a source-selection witness for s.ctx, not a proof of external clock qualification.
