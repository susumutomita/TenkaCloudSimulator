# Bounded retained HTTP probe operation contract

`ProbeOperationLifecycle` checks **22 replay-verified reachable seeds and every three-transition suffix**, not all histories of the implementation. It uses three nonzero keys plus invalid zero, two scope-owner labels, two target/service labels, backend clock 0–2 and deadlines 1–2. The retained-handle bound is two and the independent worker bound is one. Production limits are 1,024 retained per-NIC handles and eight global observer workers. No liveness or Go memory-model refinement is claimed.

The atomic transitions abstract source locking and observable publication order. Revocation prevents new admission in this model; it is not proof that a previously admitted physical callback cannot have an effect. The separate NIC bookkeeping model covers its own source-level accounting only.

## Reachable seeds and limits

The seeds cover empty/sealed state, raw/scoped retention, admitted/routed/dispatched work, timeout while pending, worker end before publication, ready and settled success, admission rejection, late failed settlement, wire success/failure, sticky poison, Host expiry, full retained quota, independent busy-worker quota, and an already-expired retained request, and a settled scoped failure after its deadline (`ScopedRetired`, the seed for eviction and replay controls). An independent prefix replay extends the same actions from `EmptyState` and checks each exact target seed. The normal formal gate requires this replay through `scripts/formal_seed_replay.py`, using the pinned harness and configuration under `scripts/formal_support/`. Both the successful prefix replay and an `InvalidTarget` semantic control must pass their expected outcomes before suite evidence can report success. Immutable-head runs use captured input bytes, without falling back to live files. This is required verification support, not an additional runtime model registration. Focused replay/control checks have passed; the full repository formal suite and other mandatory repository gates remain separate, unrun acceptance requirements for this candidate.

Three-step suffix checking explores all enabled transitions within that bound from each listed seed. It cannot establish arbitrary histories, production-scale cardinalities, scheduling fairness, crash recovery or persistence. The former broad exploration timed out without a completed result; that run is not passing evidence. No symmetry reduction is active in the accepted candidate.

No scope is claimed for packet/frame parsers, the TCP stack, gVisor, dependency vulnerabilities, filesystem/VM containment, authenticated ownership, physical revocation, provider registry correctness or an operational Battle. Source tests and full repository gates remain separate requirements.

## Semantic controls

Each non-type contract has a required exact behavioral mutation with its own invariant counterexample. Controls exercise scope rebinding; handle eviction/quota; invalid/zero/scopeless admission; duplicate deadline/adoption/dispatch; worker quota/debt; route ordering/retention; sticky result/real settlement; late backend success; unknown lookup, ownership, identity and wire projection; persistent poison and original Host deadline. A parse error, timeout or unrelated invariant failure is not a successful control.
