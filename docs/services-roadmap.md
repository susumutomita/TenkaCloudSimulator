# Service implementation and reuse queue

This is a staged implementation queue, not a claim that110services exist or work. The source-only inventory is [upstream-service-inventory.json](upstream-service-inventory.json). Kumo ce37a8f registers83service packages; LocalStack's archived8b9a79f contains48provider factories for35distinct API identifiers in services/providers.py. These are different counting methods, not comparable completeness scores. Neither upstream runtime was started for this inventory. Current LocalStack commercial offerings and rights are not inferred from archived public source.

Kumo's repository license is MIT; its standalone Go handlers/path/event models are promising reusable units. Keep complete original copyright/permission notices, exact source hashes and modification notes for each actual port. Adapt storage and authorization to current SQLite/provider boundaries rather than introducing a second memory backend. LocalStack public snapshot is primarily Python with Apache-2.0 repository notices; inspect each file, NOTICE and dependencies before any port. Its Docker/Moto/Lambda runtime cannot simply be bundled into this Go/WASI executable. The inventory itself copies no emulator implementation. The native IAM role wire fields now adapt a small MIT Kumo type; third_party/kumo-iam.json records exact source, modifications and original rights.
