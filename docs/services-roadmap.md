# Service implementation and reuse queue

This is a staged implementation queue, not a claim that110services exist or work. The source-only inventory is [upstream-service-inventory.json](upstream-service-inventory.json). Kumo ce37a8f registers83service packages; LocalStack's archived8b9a79f contains48provider factories for35distinct API identifiers in services/providers.py. These are different counting methods, not comparable completeness scores. Neither upstream runtime was started for this inventory. Current LocalStack commercial offerings and rights are not inferred from archived public source.

The initial recommendation to port selected Kumo handlers/path/event types is historical / superseded. Kumo remains a respected registry/protocol/SDK-endpoint/service-wiring design reference. Current development keeps provider-owned SQLite, authorization, route/event processing and explicit wire projections rather than adopting an emulator engine or second memory backend. Historical selected-type/lifecycle adaptations and original MIT rights remain recorded in the existing third_party/kumo-*.json provenance files (`metadataHistorical`); they are not erased or presented as current engine dependencies. LocalStack's archived Apache-2.0 source is a separately scoped historical reference, not permission for current commercial images. No clean-room, authorship or legal certification follows from the rewrite; the inventory is not implementation or acceptance evidence.
